Mandatory Technical Requirements
project must satisfy the following requirements:
The application must be developed using Android Studio.
The user interface must be implemented using Jetpack Compose.
The project must follow the MVVM (Model–View–ViewModel) architectural pattern.
Navigation Compose must be used to navigate between screens.
ViewModels must be used to connect the UI with the data layer.
StateFlow (or an equivalent state mechanism) must be used for state management.
The application must use Room database for local data persistence.
The Room database must contain at least four entities.
Basic CRUD operations (create, read, update, delete) must be implemented.
The application must include Firebase integration.
The application must follow basic UI/UX design principles.
The project must be developed incrementally throughout the semester.
The final application must compile and run without errors.


DEVELOPMENT:
IDE: Android Studio
UI Framework: Jetpack Compose
Architecture: MVVM
Version Control: Git + GitHub (mandatory)

Purpose
The course project consists of developing a fully functional Android mobile application using Android Studio and modern Android development technologies. The project is designed to integrate all theoretical and practical concepts covered throughout the semester and to provide students with hands-on experience in building a real-world mobile application.

The project must demonstrate correct usage of Jetpack Compose, MVVM architectural pattern, state-driven UI, local data persistence, cloud integration, and clean code organization. The final application should be stable, well-structured, and fully runnable.
